# Havenwell Health

A full-stack healthcare web application built with Java Spring Boot and React. Havenwell Health enables patients to find doctors, book appointments, and access patient resources through a secure, authenticated interface modeled after real-world hospital management systems.

---

## Tech Stack

**Frontend:** React, React Router, CSS Modules, Axios, Lucide React

**Backend:** Java 17, Spring Boot, Spring Security, JWT, BCrypt

**Database:** PostgreSQL

---

## Features

- JWT authentication with role-based access control

- Doctor directory with specialty and location filtering

- Appointment scheduling with interactive calendar and real-time time slot availability

- Patient resources hub including visitor info, medical records, spiritual care, e-cards, and feedback

- Authenticated users can view and manage their appointments

- Fully responsive across desktop, tablet, and mobile

---

## Getting Started

### Prerequisites

- Node.js

- Java 17

- PostgreSQL

### Frontend

```bash

cd React

npm install

npm run dev

```

### Backend

```bash

cd java

./mvnw spring-boot:run

```
